# Delivery Academy

Projeto educacional e de portfólio: recriar uma experiência de app de delivery baseada na referência em vídeo, em português, aprendendo do zero Java, JavaScript, React Native, Spring Boot, PostgreSQL, testes, Git, AWS e engenharia de IA.

## Para retomar o trabalho, leia nesta ordem

1. [`docs/PLANO_MESTRE.md`](docs/PLANO_MESTRE.md) — **fonte principal dos requisitos e do método de ensino**.
2. [`docs/STATUS.md`](docs/STATUS.md) — ponto exato de retomada, progresso verificado, bloqueios e próxima aula.
3. [`AGENTS.md`](AGENTS.md) — regras para ChatGPT, Codex, Claude ou outro assistente.
4. [`docs/DECISOES.md`](docs/DECISOES.md) — decisões e justificativas.

## Estado inicial

Somente documentação preparada localmente; ainda não afirmar que existe código, testes, repositório remoto ou deploy. O aluno criará/organizará o repositório durante os estudos para aprender Git/GitHub de verdade.

A gravação de referência se chama `283412.mp4`. Não publicar vídeo, logos, imagens ou assets de terceiros no repositório público sem autorização/licença adequada. Usar ilustrações próprias ou licenciadas.
